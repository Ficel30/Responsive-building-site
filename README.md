# 🛠️ Responsive‑building‑site

A sleek, multi-device responsive construction-themed website template built with clean HTML, CSS & JS — perfect for showcasing projects, teams, and more!

---

## 📌 Features

- **Fully responsive** layout: Fluid across mobile, tablet & desktop.
- **Hero banner** with AI-styled text + call-to-action.
- **Services & Projects** grid with hover overlays.
- Interactive **About**, **Team**, and **Contact** sections.
- Minimal JS for smooth navigation and animations.
